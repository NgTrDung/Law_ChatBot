
# 1. Project ideas

Build a chatbot to support Q&A and legal advice by fine-tuning large language models such as **BERT**, and **T5**. Combined with the **RAG (Retrieval-Augmented Generation)** method, the product is integrated on the website, helping to optimize context, increase response efficiency and bring the best experience to users.

# 2. Frameworks and Technologies

The system uses Docker for consistent deployment and optimized development. Vector data is stored and queried quickly with Qdrant, supporting the Retrieval-Augmented Generation (RAG) method. LangChain is utilized to manage the flow of data, queries, and responses effectively within the chatbot system, while Transformers from Hugging Face enable the use of advanced pre-trained models like BERT for fine-tuning and processing legal text. The backend is built with Flask to handle the API, while the frontend uses HTML, CSS, and jQuery to create a visual interface and connect to the backend. This integration ensures high performance and scalability for the legal consulting system.
